# TUI 交互说明

TUI 使用 `gitsave tui` 启动。进入前请确保目标目录已执行 `gitsave init`。

## 界面布局

- **顶部标题栏**：显示当前保存路径、所在路线、Autosave 状态与刷新间隔。执行耗时操作时会显示旋转指示，并切换终端光标形状提示繁忙状态。
- **左侧 Routes 面板（约 40% 宽度）**：列出所有路线，`*` 表示当前路线。面板底部的 Autosave 卡片显示启用状态、间隔、最大保存数、最近一次自动保存时间。
- **右侧 History 面板（约 60% 宽度）**：上半部分列出当前路线存档，下半部分 Status 卡片展示当前提交、选中提交及工作区脏文件详情。
- **底部 Notifications**：滚动显示最近 4 条系统消息/错误。
- **中央弹窗**：用于确认与输入（创建路线、切换路线、加载存档等）。

## 快捷键

| 按键 | 说明 |
|------|------|
| `q` | 退出 TUI |
| `r` | 手动刷新（同步 CLI 侧变更） |
| `Tab` | Routes 与 History 之间切换焦点 |
| `↑/↓` 或 `j/k` | 移动当前焦点的光标 |
| `PgUp/PgDn` | History 中快速翻页 |
| `Enter` | Routes 中切换路线 / History 中加载选中存档（均带确认） |
| `s` | 快速保存（需确认） |
| `l` | 加载选中存档 |
| `c` | 创建新路线 |
| `a` | 立即触发一次 autosave 检测（仅当 autosave 已启用） |

## 使用建议

- 切换路线/回滚前，若存在未保存更改会提示风险，请谨慎操作。
- 大型存档在保存/回滚时可能有短暂停顿，请等待繁忙指示结束。
- 如果需要高性能终端体验，建议使用 Windows Terminal。
