# 常见使用场景

以下场景以玩家视角描述常见问题与推荐操作。

## 1. 误操作或坏结局后快速恢复

现象：游戏失败/坏结局导致存档被覆盖或状态异常，但不想保留该状态。

推荐：
- TUI：在 History 里选择上一条正常存档，按 `Enter` 回滚并确认丢弃未保存更改。
- CLI：`gitsave load <存档>`，如存在未保存更改使用 `--force`。

## 2. 同一游戏多结局分支

现象：想同时保留多条剧情分支进度。

推荐：
- 用路线管理分支：`gitsave route create <NAME>`，切换使用 `gitsave route switch <NAME>`。
- 在 TUI 的 Routes 面板直接切换。

## 3. 关键剧情节点做标记

现象：希望快速跳回某一关键选择点。

推荐：
- 打标签：`gitsave tag "chapter-3" "关键选择点"`
- 回滚：`gitsave load --tag chapter-3`

## 4. 频繁试错（Boss 战/迷宫）

现象：高频读档试错，需要快速保存与回滚。

推荐：
- TUI：使用 `s` 快速保存；出错后选中上一条存档 `Enter` 回滚。
- CLI：`gitsave save "boss 尝试"` 结合 `gitsave history` 选择回滚。

## 5. 存档空间大、写入慢

现象：保存/回滚时终端卡顿。

推荐：
- TUI 会显示繁忙指示，请等待完成。
- Windows 端建议使用 Windows Terminal，性能更稳定。

## 6. 清理无用存档

现象：历史过多，想保留少量关键节点。

推荐：
- 用标签标记重要节点，再按需删除非关键存档。
- 配置 autosave 的最大保存数量以自动清理。

## 7. 共享或备份存档

现象：想把存档同步给其他设备或朋友。

推荐：
- 目前 `export/import` 仍为占位功能，建议直接复制存档目录或使用 Git 远程仓库。
